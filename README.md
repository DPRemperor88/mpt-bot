# Telegram-бот «Расписание и домашние задания» (МПТ, группа БИ-2-26)

Асинхронный бот для студенческой группы: парсит расписание и замены с сайта
Московского приборостроительного техникума (МПТ), показывает ДЗ, рассылает
уведомления и даёт админ-панель для модераторов и администратора.

---

## Возможности

- 📅 **Расписание на сегодня / на завтра** — парсится с `mpt.ru/raspisanie/`,
  кэшируется в SQLite и обновляется в фоне (по умолчанию раз в 3 часа).
- 🔄 **Замены в расписании** — парсятся с `mpt.ru/izmeneniya-v-raspisanii/`
  (раз в 15 минут); при появлении замены по нашей группе бот рассылает
  уведомление всем пользователям.
- 📚 **Домашние задания** — добавляются вручную через админ-панель; бот
  показывает активное ДЗ в списке и подставляет последнее активное ДЗ по
  дисциплине в строки расписания.
- 🔔 **Авто-уведомления** — о новом ДЗ (всем зарегистрированным лично) и о
  новых заменах.
- 👑 **Роли**: студент / модератор / главный администратор.
- ⚙️ **Админ-панель (FSM)**: добавить ДЗ (дисциплина → дата → текст/файл),
  список ДЗ с завершением/удалением, добавить модератора, рассылка.
- 🛡 **Антиспам** — throttling-мидлварь (ограничение частоты нажатий).

## Установка и запуск

Требуется **Python 3.10+**.

### 1. Склонируйте/скачайте проект и зайдите в папку

```bash
cd bot
```

### 2. Создайте виртуальное окружение и установите зависимости

```bash
python -m venv .venv
```

Windows (PowerShell):
```powershell
.venv\Scripts\Activate.ps1
```

Linux/macOS:
```bash
source .venv/bin/activate
```

Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 3. Настройте токен и админов

Скопируйте пример конфига и заполните:

```bash
cp .env.example .env
```

В `.env` укажите:
- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather);
- `ADMIN_IDS` — ID главных администраторов через запятую.

> ID главного админа можно узнать у [@userinfobot](https://t.me/userinfobot).

Или без `.env`: впишите токен и ID прямо в `config.py`
(`BOT_TOKEN`, `ADMIN_IDS`).

### 4. Запустите бота

```bash
python main.py
```

Бот запустится и сам создаст `bot.db` в корне проекта.

## Настройка под свою группу

Всё важное — в `config.py`:

| Параметр | Что делает |
|---|---|
| `GROUP_NAME` | Точное название группы, как во вкладке на сайте МПТ (сейчас `"БИ-2-26"`) |
| `CALL_SCHEDULE` | Время звонков: `{номер пары: "HH.MM-HH.MM"}`. Добавьте `6: …`, если бывает 6-я пара |
| `WEEK_COLOR_MAP` | Цвет плашки → неделя. Сейчас: `danger`=числитель, `info`=знаменатель |
| `SCHEDULE_REFRESH_MINUTES` | Интервал обновления расписания (мин) |
| `CHANGES_REFRESH_MINUTES` | Интервал обновления замен (мин) |
| `THROTTLE_SECONDS` | Мин. интервал между действиями пользователя |
| `TIMEZONE` | Часовой пояс |

## Как работает парсинг

1. **Расписание** (`parser.py`): страница отдаёт обычные HTML-таблицы
   (`вкладка отделения → вкладка группы → таблицы по дням`). Пары, которые
   чередуются между неделями, кодируются цветными плашками — парсер раскладывает
   их на два варианта (числитель/знаменатель). Текущую неделю бот берёт из
   пометки «Неделя: …» на сайте и по «якорю» вычисляет неделю для любой даты.
2. **Замены** (`parser_changes.py`): бот читает страницу замен, находит таблицу
   с `caption` «Группа: <наша группа>» и сравнивает снимок с предыдущим. Если
   появилась новая замена — шлёт уведомление.

Данные кэшируются в SQLite (таблицы `schedule_cache`, `changes_cache`).

## Полезные команды в чате

- `/start` — приветствие и главное меню;
- `/menu` — вернуть главное меню;
- кнопки: **Расписание на сегодня / завтра**, **Домашнее задание**,
  **Админ-панель** (видна только админам/модераторам).

## Примечания

- Бот рассчитан на один экземпляр (SQLite + `MemoryStorage` для FSM). Для
  нескольких реплик замените `MemoryStorage` на Redis-хранилище и БД на Postgres.
- Формат вывода расписания:
  ```
  История 12.00-13.30
  Иванов И.И.
  ДЗ: Прочитать параграф 4, ответить на вопросы 1-3
  ```
  Если пары или ДЗ нет — ставится прочерк «—».
